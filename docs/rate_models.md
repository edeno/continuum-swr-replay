# Replay event-rate models: two families

> **Fitted Family-B effects** (baseline rates, reward kernel, self-history
> microstructure, ladder fit) are tabulated per event type in
> [per_bin_rate_results.md](per_bin_rate_results.md), generated by
> `scripts/summarize_per_bin_rate_models.py`.

Two model families estimate **how often** non-local / SWR events occur (their
*rate*), as opposed to **what they represent** (their *content*). They answer
the same scientific question — does reward, recent reward history, or the
within-stop time course modulate replay occurrence, and does that modulation
differ between SWR-coupled and non-SWR non-local events — at two different
levels of confound control. Use **Family A** for the literature comparison and
the positive control; use **Family B** for the confound-free dissociation and
the point-process model-checking.

Both are fit on four outcome populations (tagged `outcome`): detected SWRs
(`swr`), all non-local (`non_local`), and the non-local SWR / no-SWR split
(`non_local_swr`, `non_local_no_swr`). The pooled `non_local` is the
one-population null tested against its split.

## Family A — per-stop rate (the literature-comparable layer)

- **Spec:** `MODEL_PER_STOP_RATE` (`R0` null, `R1` previous-trial reward/switch,
  `R2` + recent reward rate, `Rlag` lagged reward kernel `reward_lag1..10` +
  `is_after_switch`) in
  [`model_specs.py`](../src/continuum_swr_replay/analysis/replay/model_specs.py).
- **Estimator:** one ordinary Poisson GLM per stop on the event *count*, with a
  `log(immobility_time)` offset — `exp(coef)` is the multiplicative change in
  events per **second of immobility**
  ([`per_stop_rate_model.py`](../src/continuum_swr_replay/analysis/replay/per_stop_rate_model.py)).
- **Runner / output:** `scripts/fit_per_stop_rate_models.py` →
  `Processed-Data/replay_content/models_per_stop_rate/all_models.pkl`.
- **Cite it for:** the Ambrose 2016 / Sosa 2020 reward-rate comparison (same
  Poisson-events-per-second estimator) and the **detected-SWR positive
  control** — detected SWRs reproduce the canonical reward-gating (omission and
  recent-reward suppression; see `#19c` in
  [`../paper/claims_table.md`](../paper/claims_table.md) for the values).

This is the simple layer: one rate per stop, dwell handled as an exposure
offset. Its limitation is exactly that offset — see below.

## Family B — per-bin conditional intensity (the confound-free layer)

- **Spec:** `MODEL_PER_BIN_RATE`, an 11-model **point-process GLM
  conditional-intensity ladder** (Truccolo–Eden–Brown 2005) `M0_const … M9` in
  [`model_specs.py`](../src/continuum_swr_replay/analysis/replay/model_specs.py).
- **Estimator:** one Poisson GLM per session on the **(stop × 15 ms bin)**
  design from `aggregate_to_timebins`, with a `log(exposure)` offset; the
  within-stop time course is modelled explicitly by a `bs(tc, df=4)` spline
  rather than averaged into a per-stop dwell offset
  ([`per_bin_rate_model.py`](../src/continuum_swr_replay/analysis/replay/per_bin_rate_model.py)).
- **The ladder** toggles four blocks independently, all at one bin width
  (`BIN_S = 0.015`) so the models are nested and AIC / CV / GOF are comparable:

  | model | adds |
  | --- | --- |
  | `M0_const` | homogeneous Poisson baseline (`count ~ 1`) |
  | `M1_rew1` | previous reward (`reward_lag1`) |
  | `M2_rewhist` | reward history kernel (`reward_lag1..10`) |
  | `M2r_rewrate` | continuous recent reward rate (alt encoding) |
  | `M3_hist` | self-history / autoregression (`onset_lag1..10`) |
  | `M4_hist_rew` | self-history + reward history |
  | `M5_time` | within-stop time course (spline) |
  | `M6_time_hist` | time + self-history |
  | `M7_time_hist_rew` | time + self-history + reward history (**the full additive model**) |
  | `M8_full_switch` | + `is_after_switch` |
  | `M9_rew_x_time` | + `reward_lag1 × bs(tc)` interaction (does reward modulate the time course?) |

  The reward×time interaction (`M9`) and the switch model (`M8`) are **built and
  fit**, not deferred.
- **Runner / output:** `scripts/fit_per_bin_rate_models.py`
  (`--workers N` fans sessions over processes) →
  `Processed-Data/replay_content/models_per_bin_rate/all_models.pkl`. Plot with
  `scripts/plot_per_bin_rate_models.py`
  (→ `reward_kernel_per_bin_rate.png`, `selfhistory_autocorr.png`); the
  descriptive PSTH `scripts/_timeresolved_psth.py`
  (→ `rate_timecourse_vs_pump.png`) reads the onset/dense tables directly.
- **Cite it for:** the **dwell-, time-, reward-history- and clustering-controlled
  dissociation**. In `M7`, the immediate (lag-1) reward rate ratio dissociates —
  `non_local_swr ≈ 3.95` ≫ `non_local_no_swr ≈ 1.12` (`swr ≈ 1.45`), paired
  `non_local_swr > non_local_no_swr` in **86 % of sessions, 5/5 animals,
  p ≈ 1e-28** — while the slower **recent-reward suppression** at lags 2–10
  (RR ~0.85–0.97 per lag, ~0.6× cumulative) is **shared**. So the reward kernel
  is **boost-then-suppression**: the last trial's reward *raises* the current
  rate (and that boost dissociates by SWR-coupling), while reward accumulated
  over the preceding several trials *lowers* it (shared across populations). The
  lag≥2 suppression is a recent-reward effect; it is *consistent with* an
  RPE / relative-reward account (Kleinman & Foster 2024; Ambrose adaptive
  coding) but this GLM does not measure a prediction error, so the mechanism
  (RPE vs satiety vs reward-rate adaptation) is not established here. The
  self-history kernel is **refractory** (<1) below 60 ms and **bursty** (>1) at
  ~100 ms (events are non-Poisson).

  (These figures are from the most recent unified-15 ms-bin run; `#19c` in the
  claims table retains the original mixed-binning values — same dissociation,
  slightly different absolute coefficients, as expected from the re-binning.)

## MU — the uncertainty/value model (Family B extension)

`MU_uncertainty` (runner: `scripts/fit_uncertainty_rate.py`, output
`models_per_bin_rate/uncertainty_rate.pkl`) is an **out-of-ladder** Family-B spec
that asks whether replay rate tracks the animal's *behavioral-model* value and
uncertainty beyond the time/reward/history controls. It is the M7r base
(time spline + reward kernel + raised-cosine self-history) plus a curated block:

- **nominal (per-unit):** `p_reward_current`, `value_diff_patch`,
  `recent_switch_rate`, `trials_since_block_change`.
- **model value (per-unit):** `rpe_model` = `reward − q_chosen` from the fitted
  RL model (`qvals_table.pkl`), used *instead of* the contingency-table nominal
  `rpe` (r≈0.71).
- **RL decision variables (z-scored → per-SD rate ratios):** `switch_advantage`
  (ΔV = switch − stay value), `reward_entropy` (HMM outcome uncertainty), and the
  absolute value-update magnitudes (`global`, `unchosen_patches`). See
  [behavior_model_covariates.md](behavior_model_covariates.md).

Collinearity is controlled: `q_chosen` is dropped (r≈0.90 with ΔV, VIF 6.4);
`leaky_q_value_diff` and the leaky `q_current` stand-ins are dropped; nominal
`rpe` is replaced by `rpe_model`; `value_diff_patch` is kept (r≈−0.04 with ΔV —
independent nominal information). Final panel VIF ≤ 1.86, max |r| = 0.64. Fit
over the three populations `swr` / `non_local_swr` / `non_local_no_swr` (the
pooled `non_local` null is not fit here).

## The result holds across both families

Reward increases replay rate, and the SWR-coupled subset carries the strong
gating, in **both** estimators:

- **Family A (per-stop):** omission suppresses the non-local event rate in
  **99 % of sessions, 5/5 animals** (`is_after_omission RR ≈ 0.40`; stronger for
  `non_local_swr`, weaker for `non_local_no_swr`).
- **Family B (per-bin):** the lag-1 reward dissociation above, controlling for
  dwell, the within-stop time course, reward history, and event clustering.

The agreement across two estimators with different confound structure is the
robustness argument for `#19c` in [`../paper/claims_table.md`](../paper/claims_table.md).

## Point-process model checking (Family B)

Family B treats the event train as a point process and checks it as one via the
**time-rescaling theorem** (Brown et al. 2002): if the fitted conditional
intensity is correct, rescaling the inter-event intervals by the integrated
intensity yields a unit-rate Poisson process, so the rescaled ISIs should be
uniform (KS / Q-Q on the diagonal) and independent (flat rescaled-ISI
autocorrelation). `per_bin_rate_gof` computes these by reusing
`non_local_detector.model_checking.sorted_spikes` (`TimeRescaling`,
`point_process_residuals`, `plot_ks`, `plot_qq`,
`plot_rescaled_ISI_autocorrelation`) with `adjust_for_short_trials=True` (the
Wiener 2003 censoring correction for short/variable-length stops) — the
rescaling math is not re-implemented here. The per-fit scalars
(`ks_statistic`, `ks_within_band`, `max_isi_autocorr`, `dispersion`,
`mean_predicted`, `max_predicted`) are persisted for every fit in
`all_models.pkl`; `scripts/plot_model_checking.py` reads them for the
up-the-ladder story (`model_checking_ladder.png`) and re-fits a couple of
example sessions inline for the KS / Q-Q / ISI-autocorrelation / cumulative-
residual quartet (`model_checking_example_{rich,sparse}.png`).

What the ladder actually shows (218 sessions):

- **The within-stop time course is what calibrates the process.** `M0_const`
  fails the KS band on ~half of sessions (`ks_within_band ≈ 0.50`, non-Poisson:
  refractory + bursty), and the reward / self-history blocks *without* time
  (`M1`–`M4`) do **not** fix it (`≈ 0.37–0.55`). Adding the `bs(tc)` spline
  (`M5_time`) jumps `ks_within_band` to ≈ 0.83 and the full model `M7` to ≈ 0.91.
  The dominant misfit of the constant model is the strong post-stop rate
  transient, not the fine-timescale clustering.
- **Dispersion stays well below 0.1 (underdispersed), not → 1.** At these sparse 15 ms
  bins the Poisson deviance is not a calibrated dispersion estimate, so the
  textbook "history block drives dispersion → 1" does not apply; read KS and the
  rescaled-ISI autocorrelation (neither discretization-sensitive) instead. Mean
  per-bin count is ≈ 0.005–0.015, so the trapezoid rescaling is well-behaved on
  average; `mean_predicted` / `max_predicted` are reported so the high-rate-bin
  KS bias can be ruled out.
- **Held-out CV separates a generalizing block from an overfitting one — and
  the overfit is a parameterization artifact, now fixed.** With the lag-dummy
  history (`onset_lag1..10`), `cv_bits_per_event` is positive only for the time
  block (`M5_time ≈ +0.23`); the self-history block **overfits**
  (`M3_hist ≈ −0.25`, `M7` median ≈ −0.084, negative on 58% of sessions). The
  cause is perfect separation: on the <45 ms refractory bins the unregularized
  per-session MLE drives `onset_lag` coefficients to ≈ −25, so a held-out bin
  that *does* fire shortly after another event is assigned ≈ 0 probability and
  the log-likelihood blows up. **A smooth raised-cosine history basis fixes it**
  — replacing the 10 collinear lag dummies with 4 log-spaced raised-cosine bumps
  (the same 150 ms window) cannot separate, and lifts the median
  `cv_bits_per_event` from **−0.084 to +0.212** (positive on 89% of sessions,
  better than the dummy on 94%). The raised-cosine models (`M3r_histcos`,
  `M7r_time_histcos_rew`) are in the ladder; the dummy `onset_lag` models are
  kept for the refractory/bursty *kernel-shape* readout, which is interpretable
  per-lag where the smooth basis is not.
- **Possible within-session non-stationarity (preliminary, not established).**
  The cumulative point-process residual within a session makes slow excursions,
  and a weak population tendency for replay to rise over the session was seen
  (per-stop residual decile ramp ≈ −0.05 → +0.03; ~73% of sessions positive
  slope; not reward-rate). **But this does not survive a proper null:** because
  each per-session intercept pins the residual at both ends (a Brownian bridge),
  the right test is the bridge sup statistic `max|Mₖ|/√n`, and the *median*
  session sits at 0.83 — within the 1.36 5% band — with only ~14% of sessions
  exceeding it (vs 5% expected). So the dramatic single-session excursions are
  largely chance, and the drift is at most a weak aggregate bias, ~20% of which
  is spatial composition (it shrinks under `current_arm`/`current_patch`
  control). Treat it as **a preliminary signal, not a result.** If pursued, the
  principled handling is a **state-space / SS-GLM** baseline drifting in
  wall-clock time (gap-aware across the inter-stop runs), whose latent trajectory
  could then be correlated against task variables — a separate spec, not built
  here.

## Caveats and what each family can/can't tell you

- **Cross-family CV is not comparable.** Family A scores 5-fold per-stop mean
  log-likelihood; Family B scores 10-fold (over stops) per-bin log-likelihood
  plus `cv_bits_per_event` vs `M0_const`. Compare CV **within** a family only.
- **Lag-dummy self-history overfits; use the raised-cosine variant for
  prediction.** The `onset_lag` dummy history separates on the refractory bins
  and hurts held-out CV (`M3_hist ≈ −0.25`); the raised-cosine models
  (`M3r_histcos`, `M7r_time_histcos_rew`) fix this (median `cv_bits_per_event`
  −0.084 → +0.212). Use the dummy models only to read the per-lag refractory/
  bursty *kernel shape*; use the raised-cosine models for prediction / CV.
- **Duration is a behavioral variable, not just exposure.** Stop durations are
  bimodal — reward creates the long consummatory mode — so the offset is not a
  nuisance to be divided out; the per-second / per-bin estimators isolate the
  neural rate while the duration structure itself carries reward information.
- **Family B truncates at `TMAX = 4 s`.** It models only the first 4 s of each
  stop (~80 % of onsets; median onset ≈ 2.4 s with a long tail). Every Family-B
  conclusion is conditional on the first 4 s.

## Future work (noted, not built here)

- The long immobility tail (raise `TMAX` or add a censoring term) and slow
  session drift belong in a **state-space model**, not as fixed covariates here.
- Arm / well / patch identity covariates (hard to interpret in this rate view).
- Cross-/ensemble-history between event types (SWR↔non-local).
- The raised-cosine self-history basis (`M3r_histcos`, `M7r_time_histcos_rew`)
  already recovers the over-fit history block; an L2-penalized / Firth fit of the
  per-lag dummies remains an alternative if the per-lag kernel itself needs
  regularizing.
