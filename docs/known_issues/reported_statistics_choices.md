# Choices in the reported statistics that have not been decided

**Status:** open, except the entries marked *decided*. Each entry is a choice the
code makes today.
**Found:** 2026-11-11, while the statistics moved from the summary builders
(`src/continuum_swr_replay/reported/`) into `analysis/`, and in the review of that
code the same day (`.claude/docs/reviews/2026-11-11-reported-numbers-review.md`).
**What was done with the review's findings:** an obvious error was corrected (a
text that did not say what the code does, a silent wrong number, duplicated
code). A choice that belongs to an unsettled analysis was left as it is and
written here.

Each entry says where the choice is made (file and function), what the code
does, what is open, and what was measured. To find the values a function
reaches, look up the builder function in `paper/reported/questions.md`
("Builder function").

*Measured* means measured on the cluster's data on 2026-11-11, read-only, by the
agent that fixed that part; the counts are diagnostics, not reported values, and
were not rerun afterward. "Not measured" means the choice was read in the code
only.

When an entry is decided, write the decision in its last column (kept, with the
reason; or changed, with the commit) and do not delete the entry.
