# Scientific Presentation Design Checklist

## Quick Reference Guide

Use this checklist when creating or reviewing scientific presentations.

---

## Overall Presentation

### Structure
- [ ] Clear opening hook (intriguing question, striking image, or surprising fact)
- [ ] Roadmap slide showing talk structure
- [ ] Section dividers between major parts
- [ ] Summary slide with key takeaways (not copy of earlier slides)
- [ ] Memorable closing statement or visual
- [ ] Acknowledgments at end (not interrupting flow)

### Technical
- [ ] 16:9 aspect ratio (10" × 5.625")
- [ ] All fonts embedded
- [ ] File size < 50MB
- [ ] Tested on actual projector
- [ ] Tested from back of room
- [ ] Backup PDF created
- [ ] Backup on USB drive

---

## Per-Slide Checklist

### Typography ✓
- [ ] All fonts ≥ 16pt (absolute minimum)
- [ ] Title ≥ 32pt (36-44pt preferred)
- [ ] Body text 18-24pt
- [ ] Sans-serif fonts only (Arial, Helvetica, Calibri)
- [ ] Maximum 2 font families
- [ ] Sentence case for titles (not ALL CAPS)
- [ ] Left-aligned text (not justified)
- [ ] Line spacing 1.3-1.5x

### Layout ✓
- [ ] Title at very top of slide
- [ ] Single clear focal point
- [ ] ~50% whitespace (half of slide empty)
- [ ] All elements aligned to grid
- [ ] Safe margins (0.5-1.0" from edges)
- [ ] Nothing cut off or touching edges
- [ ] Breathing room between elements

### Content ✓
- [ ] Title is descriptive (states key finding, not generic)
- [ ] One message per slide
- [ ] ≤7 bullet points (5 preferred)
- [ ] 3-5 words per bullet
- [ ] No paragraphs on slides
- [ ] Every element serves the message
- [ ] No decorative clipart or stock photos

### Visual Elements ✓
- [ ] All lines ≥ 1pt width (2-3pt preferred)
- [ ] All plots from scientific-figures-presentation skill
- [ ] All axes labeled with units (18pt+)
- [ ] Direct labeling used when possible
- [ ] One plot per slide (or max 2 for comparison)
- [ ] All images high resolution (150 DPI+)
- [ ] Vector graphics for diagrams/plots

### Color & Contrast ✓
- [ ] Maximum 3 colors per slide
- [ ] High contrast background (white or dark gray)
- [ ] WCAG AA contrast met (4.5:1 for text)
- [ ] Colorblind-safe palette used (Wong/Okabe-Ito)
- [ ] Color + shape (never color alone)
- [ ] No gradients as backgrounds
- [ ] Semantic color consistency (same color = same meaning)

### Animation ✓
- [ ] Animations guide attention only (not decorative)
- [ ] Duration 0.3-0.5 seconds
- [ ] Consistent animation style
- [ ] Fade/wipe only (no bounce, spin, fly)
- [ ] No slide transitions (or fade only)
- [ ] Build sequence is logical
- [ ] No premature disclosure

### Cognitive Load ✓
- [ ] Single message clearly stated
- [ ] Progressive disclosure for complex content
- [ ] No split attention (text vs. what you're saying)
- [ ] Visual + verbal (not text + reading text)
- [ ] Working memory limits respected (≤7 items)
- [ ] Signal-to-noise ratio maximized

### Accessibility ✓
- [ ] Colorblind-accessible design
- [ ] Color + additional encoding (shape/pattern)
- [ ] No rapid movements (≥0.3s duration)
- [ ] Content is describable (alt-text principle)
- [ ] Reading order is logical
- [ ] No flashing or strobing

## Slide Type Templates

### Title Slide
- [ ] Large title (40-44pt)
- [ ] Subtitle/context (24pt)
- [ ] Author names and affiliations (18pt)
- [ ] Date and venue (16-18pt)
- [ ] Minimal decoration
- [ ] High impact visual (optional)

### Section Divider
- [ ] Section name only (44-52pt)
- [ ] Optional: section number
- [ ] High contrast
- [ ] No other text
- [ ] Clean and bold

### Content Slide - Visual Focus
- [ ] Descriptive title (36pt)
- [ ] One large figure/diagram
- [ ] 60-70% of slide is visual
- [ ] Brief caption if needed (18pt)
- [ ] Plot meets all figure standards

### Content Slide - Text Focus
- [ ] Descriptive title (36pt)
- [ ] 3-5 short bullets (24pt)
- [ ] Maximum 50% filled
- [ ] Optional icon or simple diagram
- [ ] Generous whitespace

### Summary Slide
- [ ] "Key Takeaways" or "Conclusions" title (36pt)
- [ ] 3 main findings (24pt, not more)
- [ ] Rephrased (not copied from earlier)
- [ ] No new information
- [ ] Memorable framing

## Data Visualization

### Plots and Charts
- [ ] Created with scientific-figures-presentation skill
- [ ] Font sizes: 20pt+ axis labels, 18pt+ ticks
- [ ] Bold title (28pt+)
- [ ] Line width ≥ 3pt
- [ ] Markers ≥ 8pt
- [ ] Direct labeling preferred over legend
- [ ] High contrast colors
- [ ] Colorblind-safe palette

### Incremental Reveal
- [ ] Step 1: Empty axes + explanation
- [ ] Step 2: Baseline/control data
- [ ] Step 3: Treatment/experimental data
- [ ] Step 4: Highlight key difference
- [ ] Step 5: Annotation with interpretation

### Tables (Avoid!)
- [ ] Tried bar chart first?
- [ ] Tried dot plot second?
- [ ] Tried text description third?
- [ ] If unavoidable: max 3×5 cells
- [ ] Cell text ≥ 18pt
- [ ] Header text ≥ 20pt, bold
- [ ] Key cells highlighted
- [ ] No gridlines (use whitespace)
- [ ] Numbers rounded appropriately

## Common Mistakes to Avoid

### ❌ Typography
- [ ] No fonts below 16pt
- [ ] No serif fonts for body text
- [ ] No ALL CAPS for extended text
- [ ] No justified text alignment
- [ ] No paragraphs on slides
- [ ] No underlines for emphasis

### ❌ Layout
- [ ] No overfilled slides (>50% covered)
- [ ] No misaligned elements
- [ ] No inconsistent margins
- [ ] No unclear focal points
- [ ] No content touching edges

### ❌ Content
- [ ] No generic titles ("Results," "Methods")
- [ ] No reading slides verbatim
- [ ] No >7 bullet points
- [ ] No multiple messages per slide
- [ ] No showing all complexity at once

### ❌ Visual
- [ ] No lines <1pt
- [ ] No unlabeled axes
- [ ] No legends when direct labels work
- [ ] No decorative clipart
- [ ] No low-resolution images

### ❌ Animation
- [ ] No decorative animations
- [ ] No inconsistent animation styles
- [ ] No transitions faster than 0.3s
- [ ] No distracting slide transitions
- [ ] No sound effects

### ❌ Color
- [ ] No low contrast (<4.5:1)
- [ ] No >3 colors per slide
- [ ] No color-only distinctions
- [ ] No gradient backgrounds
- [ ] No non-colorblind-safe palettes

## Final Pre-Presentation Checks

### 24 Hours Before
- [ ] Complete validation with validate_presentation.py
- [ ] Test on actual presentation computer
- [ ] Test with actual projector
- [ ] Verify all animations work
- [ ] Check all links (if any)
- [ ] Time full presentation with builds
- [ ] Practice in actual room if possible

### Day Of
- [ ] Presentation file on laptop
- [ ] Backup copy on USB drive
- [ ] Backup PDF version
- [ ] Remote control with fresh batteries
- [ ] Laptop charger
- [ ] Display adapters (if needed)
- [ ] Arrive early to test setup

### During Presentation
- [ ] Stand to side (don't block screen)
- [ ] Face audience (not screen)
- [ ] Pause after complex slides
- [ ] Point with laser/hand to guide attention
- [ ] Watch for audience confusion
- [ ] Stick to planned timing

---

## Post-Presentation

### Immediate
- [ ] Note which slides caused confusion
- [ ] Note where timing felt off
- [ ] Note technical issues
- [ ] Collect feedback from audience

### For Next Time
- [ ] Simplify confusing slides
- [ ] Adjust build timing
- [ ] Add clarifying annotations
- [ ] Fix technical issues
- [ ] Update based on feedback

---

## Quick Fixes for Common Issues

**"Font too small"**
→ Increase to 18pt+ for body, 36pt+ for titles

**"Slide too busy"**
→ Remove elements until one clear focal point remains

**"Too much text"**
→ Convert to bullets, diagram, or multiple slides

**"Can't read from back"**
→ Increase contrast, use bold colors, larger fonts

**"Lost track of main point"**
→ Make title descriptive, add emphasis to key element

**"Animation distracting"**
→ Remove or simplify to fade/wipe only

**"Colors hard to distinguish"**
→ Use Wong/Okabe-Ito palette + add shapes/labels

**"Slide takes too long to process"**
→ Break into progressive build sequence

## Remember

**Every slide should pass the 3-second test:**
*Can someone understand the main message in 3 seconds?*

**Every element should pass the purpose test:**
*Does this element serve the message?*

**Every slide should pass the distance test:**
*Is this readable from 30 feet away?*

If the answer is no, simplify, enlarge, or remove.
