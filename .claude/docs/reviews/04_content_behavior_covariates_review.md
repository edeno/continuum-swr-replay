# Content, Behavior, Covariate, and Choice Audit

## Findings

1. **High: the current content and choice models are not harmonized with the covariate dictionary.** The dictionary says the arm-level reward-rate target is `reward_rate_arm_k10`, that nominal value should be `p_reward_arm`, and that Q-value terms should be added as `q_current` / `q_arm` ([docs/covariate_dictionary.md:36](../../../docs/covariate_dictionary.md#L36), [docs/covariate_dictionary.md:48](../../../docs/covariate_dictionary.md#L48), [docs/covariate_dictionary.md:66](../../../docs/covariate_dictionary.md#L66)). The implemented content models still use the older 5-visit `recent_reward_rate` ([src/continuum_swr_replay/analysis/replay/model_specs.py:33](../../../src/continuum_swr_replay/analysis/replay/model_specs.py#L33), [src/continuum_swr_replay/analysis/replay/model_specs.py:192](../../../src/continuum_swr_replay/analysis/replay/model_specs.py#L192)), and the event-arm table still computes only that older history term while filling `nominal_reward_prob` with `NaN` ([src/continuum_swr_replay/analysis/replay/tables.py:1247](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1247), [src/continuum_swr_replay/analysis/replay/tables.py:1275](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1275)). The choice models likewise use `visit_recency`, `cumulative_reward`, and `recent_reward_rate`, not the dictionary's `arm_dist_rank`, `reward_rate_arm_k10`, `p_reward_arm`, or Q-value covariates ([src/continuum_swr_replay/analysis/replay/model_specs.py:697](../../../src/continuum_swr_replay/analysis/replay/model_specs.py#L697), [src/continuum_swr_replay/analysis/replay/choice_prediction.py:311](../../../src/continuum_swr_replay/analysis/replay/choice_prediction.py#L311)). Claims #19b and #19f should be labeled as using the old covariate set unless those models are rerun after harmonization.

2. **High: choice claim #19d is appropriately caveated in prose, but the implemented model is still only correlational and lacks the intended choice-distance baseline.** The model spec explicitly says `dist_to_arm` was dropped because of quasi-separation and that positive replay coefficients may partly reflect the animal's geometric choice set ([src/continuum_swr_replay/analysis/replay/model_specs.py:679](../../../src/continuum_swr_replay/analysis/replay/model_specs.py#L679)). The dictionary's proposed replacement is choice-set `arm_dist_rank` ([docs/covariate_dictionary.md:76](../../../docs/covariate_dictionary.md#L76)), but `build_choice_dataset` carries `dist_to_arm` and never carries `arm_dist_rank` ([src/continuum_swr_replay/analysis/replay/choice_prediction.py:324](../../../src/continuum_swr_replay/analysis/replay/choice_prediction.py#L324)). Until a ranked-distance or matched-choice-set sensitivity exists, claim #19d should remain phrased as a modest within-stop association, not evidence that replay independently predicts future choice.

3. **Medium-high: content occupancy claim #14 is based on a separate timebin-weighted analysis whose event and SWR definitions can drift from the canonical replay tables.** `scripts/analyze_content_occupancy.py` uses non-local timebins, `abs(ahead_behind_distance)`, nearest decoded content bin, and track-graph well distances ([scripts/analyze_content_occupancy.py:108](../../../scripts/analyze_content_occupancy.py#L108), [scripts/analyze_content_occupancy.py:149](../../../scripts/analyze_content_occupancy.py#L149)). It splits by the raw timebin `SWR_event` flag ([scripts/analyze_content_occupancy.py:133](../../../scripts/analyze_content_occupancy.py#L133)), while the canonical event tables later use event-level `is_swr` semantics ([src/continuum_swr_replay/analysis/replay/tables.py:996](../../../src/continuum_swr_replay/analysis/replay/tables.py#L996)). It also estimates well positions from immobility and proceeds with as few as four localized wells ([scripts/analyze_content_occupancy.py:76](../../../scripts/analyze_content_occupancy.py#L76), [scripts/analyze_content_occupancy.py:113](../../../scripts/analyze_content_occupancy.py#L113)). The track-graph geometry is plausible, but the manuscript should state that the reported percentages are timebin/content-mass occupancy fractions, and should add event-weighted and canonical event-level SWR sensitivities before treating the exact percentages as stable.

4. **Medium: conditional Poisson/logit identifiability guards are good, but the reward/value/switch interaction results are still exploratory.** The shared fitting code drops whole events for missing predictors, removes zero-count strata, and checks within-group rank before fitting ([src/continuum_swr_replay/analysis/replay/fitting.py:31](../../../src/continuum_swr_replay/analysis/replay/fitting.py#L31), [src/continuum_swr_replay/analysis/replay/fitting.py:114](../../../src/continuum_swr_replay/analysis/replay/fitting.py#L114), [src/continuum_swr_replay/analysis/replay/fitting.py:451](../../../src/continuum_swr_replay/analysis/replay/fitting.py#L451)). That supports the scalar-covariate rule that scalar stop/event covariates should enter conditional content models only through role interactions ([docs/covariate_dictionary.md:15](../../../docs/covariate_dictionary.md#L15)). However, `scripts/_content_reward_interactions.py` fits one behavioral interaction at a time, globally z-scores a linear log-time term, and saves only coefficient summaries, dropping `n_events`, standard errors, p-values, VIFs, condition numbers, and model provenance ([scripts/_content_reward_interactions.py:39](../../../scripts/_content_reward_interactions.py#L39), [scripts/_content_reward_interactions.py:70](../../../scripts/_content_reward_interactions.py#L70), [scripts/_content_reward_interactions.py:100](../../../scripts/_content_reward_interactions.py#L100)). Claim #19f should be marked exploratory until these fits are promoted into the audited model pipeline with diagnostics, common cohorts, multiple-comparison handling, and sensitivity to nonlinear time-since-stop effects.

5. **Medium: trajectory and occupancy metrics mostly use the correct graph geometry, but several denominators need to be named precisely in claims.** Event-arm hard fractions divide by non-local bins assigned to real arms after excluding junction bins ([src/continuum_swr_replay/analysis/replay/tables.py:1156](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1156)); posterior arm mass zeroes junction bins and renormalizes real-bin posterior mass ([src/continuum_swr_replay/analysis/replay/summaries.py:59](../../../src/continuum_swr_replay/analysis/replay/summaries.py#L59)); distance-to-arm and arm-rank covariates use shortest-path graph distances from the current well ([src/continuum_swr_replay/analysis/replay/tables.py:1215](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1215), [src/continuum_swr_replay/analysis/replay/spatial.py:80](../../../src/continuum_swr_replay/analysis/replay/spatial.py#L80)). Trajectory rollups also use graph distances, but `path_length` and step-distance include one boundary step at the start of each event ([src/continuum_swr_replay/analysis/replay/trajectory.py:399](../../../src/continuum_swr_replay/analysis/replay/trajectory.py#L399)), and `remote_fraction` in the trajectory summary is decoded-arm-not-current rather than the 20 cm remote distance regime ([src/continuum_swr_replay/analysis/replay/trajectory.py:186](../../../src/continuum_swr_replay/analysis/replay/trajectory.py#L186)). Claims #13-16 should avoid mixing these denominators.

6. **Medium: patch-destination summaries are descriptive only.** `scripts/_content_patch_destination.py` computes hard-count patch fractions and role means after switch stops, but does not provide session/animal inference, posterior-mass sensitivity, or uncertainty estimates ([scripts/_content_patch_destination.py:21](../../../scripts/_content_patch_destination.py#L21), [scripts/_content_patch_destination.py:39](../../../scripts/_content_patch_destination.py#L39)). Any claim about patch-destination content should stay as a descriptive pattern until promoted to the same conditional-model framework.

7. **Low-medium: collinearity diagnostics do not exactly match the conditional estimand.** Rank checks use within-group-centered design matrices, which is the right identifiability screen for conditional Poisson/logit ([src/continuum_swr_replay/analysis/replay/fitting.py:31](../../../src/continuum_swr_replay/analysis/replay/fitting.py#L31)). The reported condition number and VIF diagnostics are computed on the raw predictor matrix ([src/continuum_swr_replay/analysis/replay/fitting.py:420](../../../src/continuum_swr_replay/analysis/replay/fitting.py#L420)). This can misstate collinearity for predictors whose between-event component cancels in the conditional likelihood. Add centered-design condition numbers/VIFs before using those diagnostics to defend model stability.

## Verdict

The core event-arm, posterior-mass, and graph-distance machinery is largely consistent with the intended non-local content definitions, and the conditional-model fitting code has meaningful rank and complete-case protections. I would not treat claims #19b, #19d, and #19f as publication-ready causal or mechanistic claims yet. The main blockers are covariate drift from the dictionary, incomplete distance handling in choice models, and exploratory scripts that have not been folded back into the audited model-comparison pipeline.

I did not run data-heavy end-to-end fits. I ran targeted unit tests around replay summaries, fitting, choice prediction, trajectory rollups, uncertainty covariates, spatial mapping, trial sorting, model comparison, and content model selection. The run finished with 140 passed and 3 failed tests; the failures were stale-test or API-drift issues, not direct evidence that the content denominators are wrong.

## Verified Behavior

- Content denominators are explicit: hard arm fractions exclude junction bins from the denominator, while posterior fractions use non-local posterior weight after junction handling ([src/continuum_swr_replay/analysis/replay/tables.py:1156](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1156), [src/continuum_swr_replay/analysis/replay/tables.py:1173](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1173)).
- Current-arm and last-rewarded-elsewhere indicators are disjoint by construction, reducing one common interpretation error ([src/continuum_swr_replay/analysis/replay/tables.py:1187](../../../src/continuum_swr_replay/analysis/replay/tables.py#L1187)).
- Trial-history helpers sort trials and use a cutoff at reward arrival when available, which protects against post-reward leakage into event-level covariates ([src/continuum_swr_replay/analysis/replay/_helpers.py:457](../../../src/continuum_swr_replay/analysis/replay/_helpers.py#L457), [src/continuum_swr_replay/analysis/replay/_helpers.py:618](../../../src/continuum_swr_replay/analysis/replay/_helpers.py#L618)).
- Choice sets are well arms only and exclude the current arm, which matches the bandit choice interpretation ([src/continuum_swr_replay/analysis/replay/choice_prediction.py:238](../../../src/continuum_swr_replay/analysis/replay/choice_prediction.py#L238)).

## Collinearity and Separation Risks

- Conditional content models follow the correct scalar-interaction principle in the model specs, but the active specs still use old reward covariates and do not yet contain the dictionary's value/Q terms.
- Choice models are most vulnerable to task autocorrelation and geometric choice-set confounding. Dropping `dist_to_arm` avoids one separation failure but leaves the replay coefficient vulnerable to the same structure unless a ranked-distance, matched-set, or switch-only sensitivity is reported.
- The exploratory reward/value/switch interaction script should report per-session sample sizes, rank failures, VIF/condition number on the within-group-centered design, FDR-adjusted tests, and sign consistency across animals before supporting claim #19f.

## Indexing and Geometry Risks

- The main table code handles junctions conservatively for arm content, and the spatial mapping tests cover leaf/trunk and junction exclusion behavior.
- The occupancy script estimates well locations from data rather than using a canonical well table. That is a reasonable fallback, but claim #14 should include a sensitivity that requires all expected wells or uses known well coordinates when available.
- Timebin-weighted occupancy, event-arm fractions, and trajectory-event rollups are different estimands. The claims table should name which one each percentage or effect size uses.
