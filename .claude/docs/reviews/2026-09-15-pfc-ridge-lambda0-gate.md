Generated by `scripts/qa/check_pfc_ridge_lambda0.py`. The mPFC unit GLMs carry a Gaussian prior on the event-basis coefficients. The prior is a scientific choice; the solver that carries it must not be. With the penalty set to zero the solver has to land where statsmodels does, on real sessions -- which is what this checks, against the diagnostics stored when the batched fitter was first accepted.
